Пять последовательных curl-запросов HTML дали медианный TTFB 0,262 с для

- cold: готовый интерфейс за 2,43 с, response start HTML 0,150 с, 268 КБ;

Один чистый CDP-запуск Лаборатории превысил 45 с до готового `<h1>`. Повторный
Pomodoro warm-запуск с ожиданием готового timer iframe превысил 45 с. Эти случаи
показывают редкий критический stall рядом с типичными успешными прогонами.

При блокировке `arar228.github.io/*` и `cdn.jsdelivr.net/*` загрузчик перешёл к
recovery URL после первого источника, а Lighthouse завершился protocol timeout
примерно через 102 с. В этом профиле полная готовность UI при отказе обоих CDN
не подтверждена.

## Выводы и границы

Измерено: обычный cold-путь главной и Лаборатории занимает секунды; ранний iframe
был главным отличием Pomodoro по bytes и TBT; origin периодически задерживает HTML
и тело JS на десятки секунд; отказ обоих CDN оставляет длинный recovery path.

Следующие гипотезы требуют отдельных данных: место origin-stall внутри VPS,
маршрута или провайдера; вклад декодирования сцены после запуска таймера; плавность
desktop Electron после сна и на слабом GPU. Нужны read-only server latency/CPU/RAM/
restart/SQL наблюдения и профиль renderer после явного запуска.

Lighthouse TBT является лабораторной метрикой. Полевой INP и пользовательские
процентили отсутствуют. Production пока работает на исходном SHA; показатели
пакета подтверждают локальный кандидат, а выпуск требует CI exact SHA и проверки
отката.
